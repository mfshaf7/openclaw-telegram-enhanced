# Records

This directory stores historical evidence for security-significant or
production-impacting source changes in `openclaw-telegram-enhanced`.

Use change records when a Telegram-layer change affects:

- AI or model-selection behavior
- delivery shaping or approval behavior
- privileged operator surfaces such as `/platform`
- bundled or overlay runtime behavior that must be tied back to security review

For the structured record format, see
[change-records/README.md](change-records/README.md).
